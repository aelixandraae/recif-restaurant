# RÉCIF

Concept landing page for a fictional seafood restaurant on the rocks above the Îles Sanguinaires, Ajaccio (Corsica).

UX/UI portfolio project by Oleksandra Solohub. Imagery generated with AI; reviews and contact details are placeholders.

**Features:** hero, about with scroll-driven reveal, menu strip that opens into full chapter pages, gallery, reviews, booking flow with a demo confirmation, EN / FR language switch, mobile navigation.

Static site — plain HTML, CSS and JavaScript. Deployed on Vercel.
